# Tools radar: 2026-10-31

Scan window: roughly 2026-10-17 to 2026-10-31. Items already in [seen.md](seen.md) or the [playbooks](../playbooks/README.md) are left out. Several fetches were partial (changelog and release notes pages are very long), so this is a good sample, not a complete list.

## Top picks

### 1. New Anthropic SDK majors, API version 2026-10-21 and `/claude-api api-version` ([release notes](https://platform.claude.com/docs/en/release-notes/overview)) — category: Anthropic feature — from: Anthropic
- **What it does:** Python 2.0.0, TypeScript 1.0.0, Go 2.0.0 and Java 3.0.0 SDKs shipped with breaking changes; the SDKs and the `ant` CLI are now Apache 2.0. Claude Code 2.1.307 added `/claude-api api-version` to migrate API code to a newer version.
- **Why it's useful:** Anyone building agents on the API will hit these breaks; the command automates the migration instead of reading a long guide.
- **How to try:** In a project that uses the Anthropic SDK, update Claude Code and run `/claude-api api-version`. Read the migration guide linked from the release notes first.
- **Risks:** It edits your code; no extra data access. Blind version bumps can break production. Not a lethal trifecta source.
- **First exercise:** On a throwaway branch of a small SDK project, run the command, review the diff, run the tests. Worked if tests pass on the new SDK major and you can explain each change.
- **Verdict:** Try now

### 2. MCP Inspector ([linked from the MCP servers README](https://github.com/modelcontextprotocol/servers)) — category: CLI/tool — from: Model Context Protocol project
- **What it does:** Connects to any MCP server (command line or URL) and lets you call its tools by hand.
- **Why it's useful:** Debugging or building an MCP server is faster when you see raw tool schemas and responses outside the model loop. Pairs with the queued mcp-server-dev plugin.
- **How to try:** `npx @modelcontextprotocol/inspector`, then point it at a server. Check the README for current flags.
- **Risks:** Runs whatever server command you give it locally; only use servers you trust.
- **First exercise:** Launch the reference Time server in Inspector, list its tools, call one with a timezone. Worked if you see the JSON result and can read the input schema.
- **Verdict:** Try now

## Other items

### 3. claude-plugins-community marketplace ([repo](https://github.com/anthropics/claude-plugins-community)) — category: Plugin — from: Anthropic (curated mirror)
- **What it does:** Read-only mirror of community plugins submitted through Anthropic's pipeline, which says each passed automated security scanning. Listed: `eli5`, `html-plan`, `next-steps`, `quickdesign`, `testdino`.
- **Why it's useful:** A vetted-ish source of plugins beyond the official directory.
- **How to try:** `claude plugin marketplace add anthropics/claude-plugins-community`, then `claude plugin install <name>@claude-community`.
- **Risks:** Plugins can ship commands, hooks and MCP configs; scanning is not a guarantee. Read a plugin's files first. I could not verify what each plugin does.
- **First exercise:** Browse `marketplace.json`, pick one plugin, read its folder, install it, run its main command. Worked if you can say what it touches.
- **Verdict:** Watch

### 4. knowledge-work-plugins ([repo](https://github.com/anthropics/knowledge-work-plugins)) — category: Plugin — from: Anthropic
- **What it does:** 11 role plugins (productivity, data, enterprise-search, sales, legal, finance and others) with slash commands, skills and MCP connectors, built for Cowork and usable in Claude Code.
- **Why it's useful:** `data` (SQL, analysis) and `productivity` (tasks, daily workflow) fit a solo developer; the rest are role-specific.
- **How to try:** `claude plugin marketplace add anthropics/knowledge-work-plugins`, then `claude plugin install data@knowledge-work-plugins`.
- **Risks:** Connectors reach Slack, Notion, Jira, Microsoft 365 and data warehouses. Private data plus untrusted messages plus write access is a lethal trifecta risk; enable only the connectors you need.
- **First exercise:** Install `data` with no connectors and ask for a SQL query against a schema you paste in. Worked if the query and explanation are right.
- **Verdict:** Watch

### 5. Dynamic workflows for Managed Agents, beta ([release notes](https://platform.claude.com/docs/en/release-notes/overview)) — category: Anthropic feature — from: Anthropic
- **What it does:** Enabled with `"multiagent": {"type": "multiagent_20261001", "workflows": {"type": "enabled"}}`; runs report `workflow_run.*` events.
- **Why it's useful:** Multi-agent orchestration server-side without writing your own loop.
- **How to try:** Add that config to a Managed Agents session after reading the docs.
- **Risks:** Multi-agent runs burn tokens quickly and act with the session's tools; beta.
- **First exercise:** Run a two-step research task and read the event stream. Worked if you can trace each workflow step.
- **Verdict:** Watch

### 6. OpenTelemetry export for Messages API and Managed Agents, beta ([release notes](https://platform.claude.com/docs/en/release-notes/overview)) — category: Anthropic feature — from: Anthropic
- **What it does:** SDKs emit spans in seven languages to trace requests and agent sessions.
- **Why it's useful:** Real traces for debugging and evals of your own agents (see [Hamel Husain](../wiki/people/hamel-husain.md) on reading your data).
- **How to try:** Follow the SDK observability docs and send spans to a local collector.
- **Risks:** Traces can contain prompts and user data; keep the collector local.
- **First exercise:** Trace one tool-using call and inspect the span tree. Worked if each tool call shows as a span.
- **Verdict:** Watch

### 7. Reference Git MCP server ([servers repo](https://github.com/modelcontextprotocol/servers)) — category: MCP server — from: MCP project
- **What it does:** Read, search and manipulate Git repositories over MCP. Other active reference servers: Fetch, Filesystem, Memory, Sequential Thinking, Time. Many older ones (GitHub, Slack, Postgres, Sentry) are now archived.
- **Why it's useful:** A known-good example to learn from; Claude Code already has native git, so it matters mostly for other clients and learning.
- **How to try:** Follow the server's README (likely `claude mcp add git -- uvx mcp-server-git`; verify first).
- **Risks:** Can modify repos; scope to one repo. The Fetch server reads untrusted web content, so don't pair it with private data and an outbound path.
- **First exercise:** Add it and ask for summaries of the last five commits. Worked if the answer comes via the MCP tool.
- **Verdict:** Watch

### 8. Cheaper cache reads on Sonnet 5.5 — category: Workflow tip — from: Anthropic ([release notes](https://platform.claude.com/docs/en/release-notes/overview))
- **What it does:** Cache reads fell from $0.20 to $0.10 per million tokens on Oct 7.
- **Why it's useful:** Long agent loops with stable prefixes get cheaper.
- **How to try:** Put stable content (system prompt, tool definitions) first and set cache breakpoints.
- **Risks:** None beyond cost surprises if the prefix keeps changing.
- **First exercise:** Send the same long prompt twice and compare `cache_read_input_tokens`. Worked if the second call shows cache reads.
- **Verdict:** Watch

### 9. Opus 5.5 fast mode GA and SDK browser/computer-use classes — category: Anthropic feature — from: Anthropic ([release notes](https://platform.claude.com/docs/en/release-notes/overview))
- **What it does:** Fast mode left research preview (no header needed); Python and TypeScript SDKs gained browser and computer-use classes. Fast mode for Opus 4.8 is removed on Nov 30, 2026.
- **Why it's useful:** Faster interactive loops; easier computer-use prototypes.
- **How to try:** Set `speed: "fast"` on Opus 5.5 requests; see SDK docs for the classes.
- **Risks:** Computer use can act on untrusted pages; sandbox it.
- **First exercise:** Compare latency of one prompt in fast vs normal mode.
- **Verdict:** Watch

### 10. Long multi-agent Claude Code run — category: Workflow tip — from: [Simon Willison](https://simonwillison.net/2026/Oct/16/sqlite-sparql-rust/)
