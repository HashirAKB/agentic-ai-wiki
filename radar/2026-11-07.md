# Tools radar: 2026-11-07

Scan window: roughly 2026-10-24 to 2026-11-07. Items already in [seen.md](seen.md) or the [playbooks](../playbooks/README.md) are not repeated. Items are ranked by usefulness, "Try now" first. Details for registry-only items come from registry metadata, not from reading the repos.

## Top picks

### 1. Agent memory guide: memory directory, dreaming, knowledge wiki ([post](https://www.anthropic.com/research/components-of-agent-memory)) — category: Workflow tip — from: Anthropic
- **What it does:** Anthropic's Nov 6 write-up on how agents should store and consolidate memory: log transcripts, save only notes that matter to future sessions, then run an offline "dreaming" pass that corrects notes and builds wiki-style pages. It links the Managed Agents memory directory, the memory tool, a dreaming cookbook and a knowledge-wiki quickstart.
- **Why it's useful:** It is the same pattern as this wiki, with numbers: a Claude-maintained wiki raised a documents benchmark from 13% to 48% (61% combined with search). It also says to tell Claude what memory is for rather than dictate what to write, and to keep the always-loaded layer small.
- **How to try:** Read the post, then open the knowledge-wiki quickstart it links. For Claude Code, check that your `MEMORY.md` index stays short (only the first 200 lines or 25 KB load).
- **Risks:** Reading only. Memory stores can persist wrong or injected notes, so review what gets promoted into always-loaded context.
- **First exercise:** Trim one project's `MEMORY.md` or CLAUDE.md to the facts that matter every session and move the rest into linked files. Worked if a fresh session still behaves correctly with the shorter file.
- **Verdict:** Try now.

### 2. `permissions.denyInsteadOfPrompting` (Claude Code 2.1.319, [changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)) — category: Anthropic feature — from: Anthropic
- **What it does:** Denies any tool call that would otherwise wait on a permission prompt, so the turn carries on instead of stalling. Applies to terminal sessions, subagents and teammates.
- **Why it's useful:** Unattended and scheduled runs and subagent fan-out no longer hang on a prompt nobody sees. Pairs well with the already-adopted write-boundary setting.
- **How to try:** Update Claude Code, then set `permissions.denyInsteadOfPrompting` to true in project `.claude/settings.json`.
- **Risks:** Calls you forgot to allow-list are denied, so a run may finish with work skipped. It does not widen any access.
- **First exercise:** Enable it, run a headless `claude -p` task that needs one unlisted command, and confirm the call is denied and the run completes. Then add that command to the allow list and rerun.
- **Verdict:** Try now.

### 3. `/claude-api latency-optimize` (2.1.319, [changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)) — category: Skill — from: Anthropic
- **What it does:** Finds where your Claude API code adds wait time and tests faster settings against your eval.
- **Why it's useful:** Gives a measured speed-up path instead of guessing. Extends the `/claude-api` skill already in the playbooks.
- **How to try:** In a repo that calls the Claude API, run `/claude-api latency-optimize`.
- **Risks:** Runs your eval, which costs API tokens. Review proposed settings before accepting.
- **First exercise:** Point it at a small script with a simple eval, accept one suggested change, and compare time to first token or total time before and after.
- **Verdict:** Try now.

### 4. `CLAUDE_CODE_SUBAGENT_EFFORT` (2.1.316, [changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)) — category: Anthropic feature — from: Anthropic
- **What it does:** Sets the reasoning effort for subagents separately from the main session.
- **Why it's useful:** Run the lead agent at high effort and cheap fan-out helpers at low effort to cut cost and time on multi-agent runs.
- **How to try:** Set the environment variable (for example `CLAUDE_CODE_SUBAGENT_EFFORT=low`) before launching `claude`.
- **Risks:** Low effort on a subagent can lower quality for hard subtasks. No new data access.
- **First exercise:** Ask for a task that spawns three subagents to summarise three files, once at low effort and once at high, and compare quality and elapsed time.
- **Verdict:** Try now.

## Watch

### 5. Message threads, beta ([release notes](https://platform.claude.com/docs/en/release-notes/overview)) — category: Anthropic feature — from: Anthropic
- **What it does:** With the `message-threads-2026-08-12` beta header the API keeps conversation state server-side, so later requests send only new messages. Threads expire 5 minutes after the last request.
- **Why it's useful:** Smaller requests and faster time to first token in long chats and agent loops.
- **How to try:** Add the beta header on the Claude API and follow the docs linked from the release note.
- **Risks:** Conversation content is stored server-side for up to an hour. Beta, so the shape may change.
- **First exercise:** Build a 10-turn chat loop with and without threads and compare request payload size.
- **Verdict:** Watch.

### 6. Usage and Cost Analytics API, beta ([release notes](https://platform.claude.com/docs/en/release-notes/overview)) — category: Anthropic feature — from: Anthropic
- **What it does:** Endpoints under `/v1/organizations/analytics/` report token usage and cost, grouped by model, workspace, API key or user.
- **Why it's useful:** Shows which agent or key burns the budget. Needs organization admin access, so it matters mainly for team or org accounts.
- **How to try:** Use the `analytics-usage-cost-2026-08-24` beta header with an admin key.
- **Risks:** Admin keys are powerful; keep them out of agent-reachable environments.
- **First exercise:** Pull a week of cost grouped by model and check it matches the Console.
- **Verdict:** Watch.

### 7. Opus 4.8 fast mode removal on 2026-11-30 ([release notes](https://platform.claude.com/docs/en/release-notes/overview)) — category: Anthropic feature (deprecation) — from: Anthropic
- **What it does:** `claude-opus-4-8` requests with `speed: "fast"` will return an error after Nov 30. Anthropic recommends Opus 5.5 (see the [fast mode playbook](../playbooks/opus-fast-mode.md)).
- **Why it's useful:** Catches a breakage before it happens.
- **How to try:** Search your code for `claude-opus-4-8` with fast speed and switch to Opus 5.5.
- **Risks:** None from reading; the risk is the error if you miss it.
- **First exercise:** Grep your repos for the model ID, change one call, and confirm it still returns.
- **Verdict:** Watch (act before Nov 30 if you use it).

### 8. Agent SDK hook `onFailure: "block"` (2.1.317, [changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)) — category: Anthropic feature — from: Anthropic
- **What it does:** A failing SDK hook callback now blocks the action instead of letting it through.
- **Why it's useful:** Makes SDK-built guardrail hooks fail closed.
- **How to try:** Set `onFailure: "block"` on a hook callback in the Agent SDK.
- **Risks:** A buggy hook can halt the agent entirely.
- **First exercise:** Write a hook that throws on purpose and confirm the tool call is blocked.
- **Verdict:** Watch (useful once you build with the SDK).

### 9. MCP tasks run in the background (2.1.319, [changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)) — category: Anthropic feature — from: Anthropic
- **What it does:** MCP tool calls that a server runs as tasks move to the background and Claude is told when they finish. `CLAUDE_CODE_DISABLE_MCP_TASKS=1` turns it off.
- **Why it's useful:** Long-running MCP tools no longer block the session.
- **How to try:** Update Claude Code. It applies to servers that support tasks.
- **Risks:** Background results arrive later, so check state before relying on them.
- **First exercise:** Build a tiny task-capable server with the mcp-server-dev plugin and watch the session continue while it runs.
- **Verdict:** Watch.

### 10. datasette-agent 0.5a0 ([Willison](https://simonwillison.net/2026/Nov/3/datasette-agent/)) — category: CLI/tool — from: Simon Willison
- **What it does:** Adds a chat panel beside Datasette pages so you can build an app and modify it from the chat. The companion datasette-apps 0.3a0 asks for user approval on write queries. Details come from the blog index, not the repo.
- **Why it's useful:** A concrete example of an approval-gated agent over a database.
- **How to try:** Follow the install steps in the linked post.
- **Risks:** Alpha. Gives an agent query access to your data; review the write-approval behavior.
- **First exercise:** Load a small CSV into Datasette, ask the panel for a summary query, and check it returns the right counts.
- **Verdict:** Watch.

### 11. ai.adeu/adeu, DOCX redlining MCP server ([repo](https://github.com/dealfluence/adeu)) — category: MCP server — from: dealfluence (registry v1.7.1, May 2026)
- **What it does:** Edits Word documents as tracked changes.
- **Why it's useful:** Lets an agent revise a document with reviewable redlines instead of rewriting the file.
- **How to try:** Find it in the [MCP registry](https://registry.modelcontextprotocol.io/v0/servers) and follow the repo README.
- **Risks:** Reads and writes local documents, which may be private. No untrusted-content or send-out path by itself. Third party, not vetted here.
- **First exercise:** Redline a sample one-page doc with two changes and check both show as tracked changes in Word.
- **Verdict:** Watch.
