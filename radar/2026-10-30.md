# Tools radar: 2026-10-30

Nine items from the last ~2 weeks (plus a few longer-lived official resources). Every item was confirmed at its own official page or repo.

## Top picks

### 1. permissions.blockWritesOutsideWorkingDirectories ([changelog 2.1.314](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))
- Category: Anthropic feature — from: Anthropic (Claude Code)
- **What it does:** Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode.
- **Why it's useful:** A hard guardrail when running agents in auto or skip-permissions modes, so a runaway session cannot touch files elsewhere on disk.
- **How to try:** Update Claude Code, then set the key under `permissions` in `settings.json` (see Claude Code settings docs).
- **Risks:** Reduces risk. It covers file-edit tools only; Bash commands are governed separately.
- **Verdict:** Try now

### 2. Official plugin directory ([anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official))
- Category: Plugin — from: Anthropic
- **What it does:** Curated catalog of Claude Code plugins (bundles of commands, subagents, skills, hooks, MCP config), with Anthropic-made and third-party sections.
- **Why it's useful:** The safest place to find plugins; avoids random GitHub installs.
- **How to try:** In Claude Code run `/plugin` > Discover, or `/plugin install <name>@claude-plugins-official`.
- **Risks:** Plugins can run hooks and MCP servers with your permissions. Anthropic states it cannot verify third-party plugins, so read before installing. Lethal trifecta depends on the plugin.
- **Verdict:** Try now

### 3. How the Claude Code team does code review ([blog](https://claude.dev/blog/solving-code-review-at-anthropic/), via [Simon Willison](https://simonwillison.net/2026/Oct/16/code-review/))
- Category: Workflow tip — from: Anthropic Claude Code team
- **What it does:** Reframes review from "did a human read it" to "what could go wrong, and which check catches it best". Claude reviews and fixes most changes before a human looks; review is continuous.
- **Why it's useful:** A concrete model for solo developers: automated review passes first, human attention reserved for design questions.
- **How to try:** Run a Claude review pass (e.g. the `/code-review` skill or a review subagent) before every commit; list risks per change and pick the check for each.
- **Risks:** None beyond normal repo access. I only read a short quoted summary, so read the full post.
- **Verdict:** Try now

## Other items

### 4. Anthropic skills repo ([anthropics/skills](https://github.com/anthropics/skills))
- Category: Skill — from: Anthropic
- **What it does:** Example skills (web app testing, MCP server generation, docs, design) plus the skill spec and template.
- **Why it's useful:** Reference patterns for writing your own `SKILL.md`; ready-made document skills.
- **How to try:** `/plugin marketplace add anthropics/skills`, then `/plugin install example-skills@anthropic-agent-skills`.
- **Risks:** Document skills are source-available, not open source. Anthropic labels the examples as demonstration; test first.
- **Verdict:** Watch

### 5. Agent Skills open standard ([announcement](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation), [agentskills.io](https://agentskills.io))
- Category: Anthropic feature — from: Anthropic / Agentic AI Foundation (Linux Foundation)
- **What it does:** Agent Skills donated to a vendor-neutral foundation (Oct 22); 70+ platforms reportedly support it. Proposed roadmap includes versioned releases and security guidance.
- **Why it's useful:** Skills you write should work across Claude, Cursor, Copilot and others.
- **How to try:** Read the spec at agentskills.io; write skills in the standard `SKILL.md` format.
- **Risks:** Installing third-party skills is running untrusted instructions; security guidance is still only proposed.
- **Verdict:** Watch

### 6. Idle compaction ([changelog 2.1.314](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))
- Category: Anthropic feature — from: Anthropic
- **What it does:** In VS Code and the Desktop Code tab, a conversation over 200K tokens left idle is summarized, and the summary is used on your next message if the prompt cache expired.
- **Why it's useful:** Cheaper, faster resumption of long sessions.
- **How to try:** Update; it is automatic in those surfaces.
- **Risks:** Summaries lose detail; keep key decisions in CLAUDE.md or notes.
- **Verdict:** Watch

### 7. claude_code.safety_event telemetry ([changelog 2.1.307](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))
- Category: Anthropic feature — from: Anthropic
- **What it does:** OpenTelemetry event for every tool call stopped, prompted or sent back by a permission rule, auto mode, hook, or sandbox.
- **Why it's useful:** Shows how often guardrails fire, to tune permissions.
- **How to try:** Enable Claude Code OpenTelemetry export and look for the event.
- **Risks:** Needs a telemetry backend; low value for casual solo use.
- **Verdict:** Watch

### 8. Claude Haiku 5.5 ([announcement](https://www.anthropic.com/claude-haiku-5-5))
- Category: Anthropic feature — from: Anthropic
- **What it does:** Anthropic's fastest small model, aimed at summarization, subagents and browser use (Oct 7).
- **Why it's useful:** Cheap, fast model for subagents and bulk tasks.
- **How to try:** Model id `claude-haiku-5-5`; select via `/model` or a subagent's `model` setting.
- **Risks:** Weaker on hard reasoning; check pricing and limits on the announcement page.
- **Verdict:** Watch

### 9. Redesigning source control at Anthropic ([post](https://www.anthropic.com/research/redesigning-source-control))
- Category: Workflow tip — from: Anthropic
- **What it does:** Describes Scion, an internal online-first source control system for a very high-merge monorepo. Authors say it is not a general git replacement.
- **Why it's useful:** Transferable ideas only: trunk-based short-lived changes, post-merge tests, reviewing intent, pushing back on over-engineered AI code.
- **How to try:** Nothing to install; Scion is not released.
- **Risks:** None.
- **Verdict:** Skip-for-now (read for ideas)
