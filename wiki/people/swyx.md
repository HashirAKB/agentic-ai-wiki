## Key practices (The Rise of the AI Engineer)
Source: https://www.latent.space/p/ai-engineer
- AI engineering is a subdiscipline of software engineering: applying foundation models (via API or open weights) inside products, rather than training them.
- Rationale: research talent is concentrated in a few labs, and software engineers far outnumber researchers, so an in-between role fills the gap.
- Prompt-first prototyping lets you validate an idea before collecting data for fine-tuning, which reverses the old ML order.
- Code stays central: good products combine ordinary code with LLM calls.
- Core of the job: owning your product's data and evals; shipping user-facing work fast.
- Stack: retrieval, vector search, chaining, agents; Python and JavaScript.
- Entry advice: no PhD needed; learn by using and building with products rather than starting from papers.
