## Agentic Engineering Patterns (guide, started Feb 2026)
A book-shaped, growing guide on getting good results from coding agents like Claude Code and Codex.

- **Agentic engineering vs vibe coding:** experienced engineers using agents to amplify their expertise, as opposed to not caring about the code.
- **Writing code is cheap now:** producing new code is nearly free, but good code still costs real effort; build new habits around that.
- **Hoard things you know how to do:** keep a collection of working examples and techniques so agents can recombine them.
- **AI should help us produce better code:** use agents to pay down tech debt, consider more options, and run a compound engineering loop.
- **Anti-pattern:** don't push unreviewed agent code onto collaborators.
- **Working with agents:** understand how agents work (LLM + system prompt + tools in a loop, token caching), use Git deliberately with agents, use subagents (explore, parallel, specialist).
- **Testing and QA:** red/green TDD (test first so agents write tighter, more reliable code), first run the existing tests, agentic manual testing (browser automation, have agents take notes).
- **Understanding code:** linear walkthroughs of a codebase and interactive explanations generated by the agent.
- **Annotated prompts and his prompt library** (proofreader, alt text, artifacts).

## Security (to verify against primary post)
- Lethal trifecta: an agent with private data + exposure to untrusted content + ability to communicate externally can be exploited via prompt injection. Important for any agent Hashir builds.
