# Agentic AI Wiki

A public, LLM-maintained knowledge base, built on [Andrej Karpathy's LLM Wiki pattern](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).

- Best practices from credible AI practitioners on working with agents and LLMs
- Kept current by Claude on a daily scheduled run (learning in public)

Start at [index.md](index.md). Conventions are in [CLAUDE.md](CLAUDE.md). Claude Code updates this repo every morning through a GitHub Action ([workflow](.github/workflows/daily-research.yml), [instructions](.github/claude/daily-research.md)), and scouts new Claude features, connectors, plugins, skills and MCP servers every Saturday ([radar instructions](.github/claude/weekly-tools-radar.md), results in `radar/`); see [log.md](log.md) for history and [proposals.md](proposals.md) for suggested changes awaiting approval.
